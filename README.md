# AI and ML Basics

Standalone learning repo. Work here on its own — no other repos required.

**Phase (for your own roadmap):** Capstone

## Context

LLMs, embeddings, vector databases, and RAG are now part of full-stack product work. This repo is a practical intro to building with those pieces — APIs and patterns, not a research degree — and it does not depend on any other curriculum repo.

This repository is the single place for everything related to **AI and ML Basics**: notes, exercises, and small projects. Clone it, open it, and treat it as a complete unit of study.

## Scope

- LLM APIs: prompting, tools, limitations
- Embeddings and similarity
- Vector databases
- RAG (retrieval-augmented generation) pipelines
- Prompt engineering that is systematic, not vibes-only

## Outcomes

When you are done with this repo, you should be able to:

- Build a small RAG-style demo end to end in projects/
- Explain embeddings vs fine-tuning vs prompting tradeoffs
- Handle failure modes (hallucination, retrieval misses, cost/latency)

## How to work in this repo

1. Read / write concept notes under `notes/`.
2. Solve practice problems under `exercises/`.
3. Ship at least one small project under `projects/` that forces the ideas to stick.
4. Tick the checklist below as you go.

You do not need any other curriculum repo open while you work here.
